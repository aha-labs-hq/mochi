# Repository presentation

`mochi-workflow.jpg` is a crop of the public https://mochi.host/ homepage
captured on 2026-11-01. It preserves the website's example conversation,
character, source links and public-beta label. It is an illustration of the
workflow, not a customer transcript or a native-app acceptance record.

The image was cropped and resized, without changing its contents, to
1600 × 953 px and encoded as JPEG. Both README languages link it to the
interactive website examples and label its provenance visibly.

Keep the English and Chinese README product promises consistent. The public
download page owns current version and requirements; source can be ahead of
the downloadable beta. Links from the README use the existing site analytics
parameters `utm_source=github`, `utm_medium=readme`,
`utm_campaign=public-launch`; they do not add another collector.
