Grok Bot / explicit task scope

把能力挂到这一件事上。

Grok 的强项是显式的 Marketplace 与 @ 任务挂载：工具在哪里、是否参与当前任务，一眼能分清。

连接器已安装 · 当前任务未挂载

安装成功，不等于这次工作会用到它。

这是一个概念重排：左侧是插件入口，右侧是任务作用域。Mochi 借用这个清晰度，但把“@”换成普通成员也能理解的任务详情。

Muse / progressive oversight

连接之后，仍然看得见。

Muse 的强项是把连接、权限、活动、目标和审批组合成持续监督，而不是一次性 OAuth 完成页。

自然语言连接 · 权限持续可调

“连接我的 Gmail”是入口，权限卡才是边界。

这里保留 Muse 的渐进授权思想：先读，再写；一次、当前任务、当前站点或以后都允许，分别成为用户能理解的选择。
