本轮依据用户明确选择的“干净、收敛的短绒边缘”，从生成源头替换根图和全部八个动作。此前的[同日审计](motion-quality-audit-2026-09-14.md)对应用户否决的版本，不是本轮验收证据。新素材已同步到主工作区；最终本机重启记录见文末。

用户随后指出持续状态每轮退回静帧，以及睡眠／苏醒过渡仍不自然。本页记录短绒素材替换阶段的检查；原来的连续播放结论未覆盖持续动作的正确所有权，不能作为这两项问题的完成证据。后续修正见 [持续状态与睡眠节奏复核](motion-sustained-audit-2026-09-14.md)。

## 根因与处理

1. 原根图自身包含松散长毛、碎屑状轮廓，旧全身参考图也包含卷曲长纤维。仅修抠图不能改变生成源的材质。新 RGBA 根图由图像模型生成干净短绒外形，运行时只做等比例 Lanczos 缩小；全身参考也只依据新根图重新生成。没有用侵蚀、轮廓裁切或模糊把长毛改成短绒。
2. 旧背景提取会把卷毛包围的小片偏色蓝底保护成不透明前景，这些错误颜色又可能成为边缘去污染的采样来源。共享提取器现在仅释放外缘邻域内有面积和距离限制的蓝底口袋，并区分“受保护的内部颜色”与“可靠的不透明前景样本”。已知透明背景的回归样本由错误的 alpha 255 降至 5，眼睛和深层道具仍保留。
3. 旧最小柔边比例和周长指标奖励松散毛边，不能代表用户新选定的材质。现在每一帧都与同一根图比较边缘过渡宽度和细轮廓粗糙度；粗糙度用同一形体的粗化轮廓归一化，避免把腿或道具算成乱毛。界限统一来自 manifest，首尾衔接阈值没有放宽。已知 alpha 的测试覆盖干净抗锯齿、宽光晕、碎边和完整四肢形体。
4. 播放器保留单个生成曝光，不再溶解相邻帧形成双眼或双道具；反向退出必须实际画出第 0 帧后才交给静图。运行时不再二次改色。状态静图全部提取自各自视频的最后一帧。
5. 本轮实际复核发现 UI 测试会复用上次构建的图集：新根图配旧图集时，八个首帧比较均失败。测试入口已改为先调用同一个资源构建器，再编译界面；刷新后八个动作全部逐像素通过。原生构建和 UI 测试不能同时写同一 staging 目录。

## 每个动作的复核

逐帧对照覆盖全部 768 个运行时曝光及相应原片帧，另检查源视频多出的末帧。浅灰、深灰、粉色底检查外轮廓、眼睑、耳尖、爪子和道具接触处；原片与透明成片的对照图、接缝图、数值报告保存在上述目录的 `evidence/`。全分辨率帧和正反播放页面在 `frames/index.html`。

| 动作 | 采用候选 | 重点观察与拒绝依据 |
| --- | --- | --- |
| 眨眼张望 | v2 A | 一次双眼眨动后小幅横向看。逐帧检查眼睑与瞳孔；其他版本的额外眨眼、夸张耳动或睫毛被拒。 |
| 竖耳 | v1 B | 双爪保持落点，轻微抬头后回原位；拒绝整体倾斜和明显拉长身体的版本。 |
| 工作台 | v1 B | 小型暖深色台面，三枚浅色指示点。重点检查 10–16 帧出现和 74–80 帧退出；没有双道具、漏抠洞或大色块。拒绝大型面板、立柱与折耳版本。 |
| 入睡／苏醒 | v1 C | 16–40 帧闭眼，40–95 帧稳定；闭眼黑线完整，身体与根图同色。拒绝明显眉盘和厚眼睑版本。反向播放使用同一源视频。 |
| 需要关注 | v2 C | 下方一枚哑光赭色毛毡球，视线向下后回正。球实际比提示词要求更大，视觉上仍位于爪间且不挡脸；不能声称模型完全遵循了尺寸提示。拒绝玻璃球及更重的道具版本。 |
| 整理思绪 | v2 C | 三枚球低位展开、归拢、回到下方，脸部保留净空。v1 C 在放大原片第 40 帧时发现粉球碰鼻，已拒绝并重新生成。 |
| 思绪装满 | v1 C | 三枚小球从上方叠放在两耳之间，一次上看后停稳；拒绝更夸张的耳动和不自然的初始球裁切。 |
| 完整跳跃 | v2 C | 全身始终保持短绒，检查起跳四肢、空中后爪、着地前爪和尾巴回收。旧全身参考导致的长毛版本及后脚平截版本被拒。12/32/60 帧分别作为探头、起跳、落地提示点；最终回到完全相同的根图。 |

整理动作第 15、16、73、74 帧触发内部透明提示。放大原片及 alpha 后，确认标记区域是球、双爪和身体下沿之间真实的蓝底空隙，没有猫身被抠穿。其余七段没有内部透明提示；全部八段的外缘蓝／青色标记为 0。提示是待解释的测量信号，不是自动补洞依据。
