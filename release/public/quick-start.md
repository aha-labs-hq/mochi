# 开始使用 Mochi

Mochi 是运行在 Mac 上的应用，为你的团队请来住在飞书群里的项目伙伴；默认的伙伴叫麻薯。你可以在飞书中让它依据所选项目和资料回答问题、核对进展，并把明确交代的决定更新到 GitHub Issue。

Mochi 目前只能连接飞书中国版（feishu.cn）的组织，不支持 Lark；界面只有简体中文。

## 安装

1. 从 [官方下载页]({{DOWNLOAD_PAGE_URL}}) 下载 `Mochi.dmg`。适用的 Mac 和 macOS 版本写在下载页上。
2. 打开安装包，把 Mochi 拖到 Applications，推出安装磁盘，再打开 Applications 中的 Mochi。
3. 按 Mochi 中的提示准备后台组件。macOS 会请求一次标准管理员授权；如果你没有管理员账号，请设备管理员完成这一项。

所有设置都在 Mochi 和服务方的官方授权页面完成。

## 连接你的账号和项目

- 在 Mochi 中连接自己的 ChatGPT 账号。也可以在设置的模型连接中添加你选择的模型 API；模型 API 由对应服务方独立计费。
- 按提示在飞书官方页面扫码，核对机器人身份并同意授权。组织要求管理员审批时，需要等待真实批准，再回到 Mochi 继续。
- 连接自己的 GitHub 账号，为 App 安装选择允许访问的项目，并在 Mochi 中明确打开要使用的项目。只完成账号登录还不等于已获得项目访问。
- 需要读取共享邮箱时，在该伙伴的连接器中另行授权，再打开要读取的邮箱。邮箱能力只读。
- 查看伙伴的群列表，确认哪些群允许回应，再点“开始值班”。新伙伴默认休息；打开设置或保存嘱咐不会让它自动开始工作。

**同一位伙伴参与的群共享记忆。** 请只把它加入适合共享工作上下文的群；同一群中的讨论可能成为它在其他参与群回答时的依据。不同伙伴分别保留自己的记忆、嘱咐、飞书/GitHub 连接和访问范围；模型连接由应用共用。

## 在飞书交代工作

在新话题中 @ 机器人提出请求，之后可以在同一话题继续补充。可以询问项目进展、要求更新已有 Issue，或者交代未来的调查和总结。请核对它给出的依据；有读取缺口时，结论只适用于已经获得的资料。

安排的结果默认发到原来的群，附上原讨论链接；明确要求安静跟进时才回复约定话题。Mac 关机、休眠、断网或伙伴休息期间，无法承诺准点执行。定时工作只调查、总结和提醒，不会把过去的交代当成新的修改项目授权。安排可以在飞书修改，也可以在设置中暂停、恢复或取消。

群开关只停止接受新消息，已经接下的工作仍会完成。关闭群、取消项目或邮箱选择不删除已有工作记忆。更换共用模型连接时，使用该连接的伙伴都需要空闲；暂停或调整某位伙伴只影响它自己。

图片和文本可以作为资料；PDF、Office、音视频及部分复杂飞书对象尚无内置正文解析器，Mochi 会说明资料缺口。公开研究会向相应搜索服务和网站发送查询及请求，敏感内容请谨慎交代。

## 更新、断开和卸载

公开测试版暂不提供应用内更新：新版本发布后，先按下文卸载并保留数据，再从下载页安装新版本；不要把新版本直接拖进“应用程序”覆盖旧版。正式版起，在设置的“关于与更新”或应用菜单里检查更新。默认在后台检查和下载；准备好后点“空闲时更新”，Mochi 会等已接下的工作及回复发送完成，再重新打开。安装前可以取消等待；下载可以暂停和继续。

“空闲时自动安装”默认关闭，只有你开启后才会自动重新打开，而且未保存的设置会阻止自动安装。账号、伙伴、访问范围和工作记忆会保留；更新中断时按 App 给出的恢复动作继续。首次准备和显式修复使用标准 macOS 管理员授权，常规更新使用已配置的更新服务；系统撤销后台权限时需要重新允许。更新的短暂离线期间无法承诺新消息实时接收。

不再需要某项连接时，可以在设置中断开或取消选择。要彻底撤销服务端授权，请同时到对应服务方的账号或组织设置中处理；本机断开不保证所有服务端授权都已撤销。

在设置的“关于与更新”中选择“卸载 Mochi”。默认保留连接、设置和工作记忆；若不再需要，勾选“同时永久删除此 Mac 上所有 Mochi 数据”，再确认卸载。此选择会删除所有伙伴的数据，无法恢复。等待已接下的工作与回复发送完成后，App 会关闭并完成卸载；等待期间可以取消。只把 Mochi 拖到废纸篓不会停止后台服务，请使用 App 内的卸载。

本机卸载不会删除已经发到飞书的消息或写入 GitHub 的 Issue，也不会删除服务方保留的数据。

## 获取帮助

遇到问题请先使用 Mochi 中给出的恢复动作。需要帮助时，在设置中导出运行诊断，通过 [支持入口]({{SUPPORT_URL}}) 发给我们。诊断只包含版本、状态和固定问题码；不要附上密码、密钥、验证码、完整聊天或原始系统日志。

数据如何处理见 [隐私说明](PRIVACY.md)。
