# Avatar generation

Generated September 15, 2026 through the user-selected desktop `seed-media.sh`
image mode. Provider: BytePlus Ark. Model: `dola-seedream-5-0-pro-260628`
(`image-pro`). Each request used text only, square aspect ratio, `2K`,
`watermark: false`, and `optimize_prompt_options.thinking: disabled`.
The script appended `Use a 1:1 aspect ratio.` to each prompt below.

Reference images were viewed for aesthetic
understanding only. They were not uploaded, cropped, traced or transformed.
These are direct Seedream image outputs, not built-in Codex output or
video-frame extractions. All three are non-photorealistic illustrations.
Rejected studies and the previously integrated photographs are excluded from
production assets.

The service returned 2048 × 2048 JPEGs; `originals/*.jpg` preserves those bytes.
Each renderer PNG is a full-frame Lanczos3 resize to 128 × 128, displayed at
30 points. There is no crop (left 0, top 0, width 2048, height 2048), retouching,
recoloring or added texture. Originals and 30-pixel reductions were visually
inspected. This records implementation review, not user approval.
Credentials, signed download URLs and the local script are not bundled.
