更新于 2026 年 10 月 23 日。

这份说明描述当前版本的 Mochi 如何处理数据。Mochi 运行在你的 Mac 上；下面列出的每个服务各自处理收到的数据，并受该服务方自己的规则约束。

## 本机工作记录

Mochi 在你的 Mac 保存账号连接、访问范围、伙伴的嘱咐、工作记录、消息处理标识和安排。已进入模型对话的内容可能保留在该伙伴的历史工作记录中。当前任务的资料副本和临时执行文件在任务结束后清理；这不等于删除历史工作记录。

同一位伙伴参与的群共享记忆，可能在一个群回答时参考另一个参与群的讨论。不同伙伴分别保存自己的记忆和连接。群、项目和邮箱的开关限制以后接受或读取的内容；关闭开关不会擦除已经进入工作记录的信息。

模型账号和命名模型 API 连接由应用共用，每位伙伴选择具体连接。连接凭据在本机的专用存储中处理，API 密钥不进入网页界面、聊天记录或导出的诊断。飞书官方组件可能使用本机文件保存加密凭据及其密钥，因此本机访问控制不能抵御能够以同一 macOS 用户执行代码的软件。不要把本机存储理解为对所有本机程序都不可读。

## 数据会发给谁

- **模型服务**：所选模型会收到完成任务所需的消息、历史上下文、图片、嘱咐和工具读取结果，包括你允许读取的项目、文档或邮件内容。用 ChatGPT 登录时，请求发给 OpenAI；用你配置的模型 API 时，请求发给你填写的 Responses API 地址。共享邮箱只读不代表正文只留在本机；模型分析时仍可能向模型服务发送正文。
- **飞书**：Mochi 通过你的机器人读取获准群消息和资料，并在相应群或话题发送答复。共享邮箱使用另行授予的用户读取权限，只访问明确选择的邮箱，不发送或修改邮件。
- **GitHub**：Mochi 只访问明确选择的项目。Issue 修改经 Mochi 的 GitHub 授权服务核对，再以 Mochi Companion App 的身份写入 GitHub。该服务会处理完成当前请求所需的访问令牌、账号/项目标识和拟写入的 Issue 内容；完整聊天历史不作为这项授权请求发送。
- **头像**：Mochi 的界面直接从 GitHub 和飞书的图片服务器加载项目所有者、群和机器人的头像。
- **公开研究**：搜索语句发给 DuckDuckGo，它不可用或没有结果时再发给 Bing；访问的地址和网络请求发给对应网站。Mochi 不提供登录态浏览器，也不能为公开研究读取你其他应用的登录内容。
- **软件更新**：检查和下载向 `downloads.mochi.host` 发出网络请求，服务方会收到 IP 地址等常规连接信息；请求不包含伙伴名称、账号连接、聊天或诊断报告。自动检查与自动下载可分别在“关于与更新”关闭。本机只保存更新偏好、候选摘要、下载进度及安装结果，不自动上传更新诊断。
- **Cloudflare**：Mochi 官网和 GitHub 授权服务运行在 Cloudflare 上，Cloudflare 处理它们的网络连接和运行信息。授权服务的应用日志记录请求关联标识、账号/项目数字标识及结果码，不记录令牌和拟写入的正文，最长 7 天后自动删除。
- **Aha Labs**：通过官网申请表提交的内测申请（此前也包括支持请求）保存在 Aha Labs 的飞书多维表格中，不对其他填写者开放，申请或问题处理完后 90 天内删除。Aha Labs 用你留下的称呼、联系方式和需求沟通试用安排；团队、职能、规模和准备情况为选填，用于了解试用场景。写给 {{PRIVACY_CONTACT_EMAIL}} 的邮件经 Cloudflare 转发，保存在 Aha Labs 使用的 Google 邮箱（Gmail）中。

模型服务的额度、保留期限和使用政策由你所选服务及账号设置决定；Mochi 不承诺服务方不保留内容。请按团队要求选择模型连接、参与群和访问范围。

## 跨境传输

模型请求、飞书消息和 GitHub 读取由你的 Mac 直接发给对应服务，不经过 Aha Labs 的服务器；只有修改 Issue 的请求经过 Mochi 的 GitHub 授权服务。

OpenAI、GitHub、Cloudflare 和 Google 都是美国公司，在中国大陆以外处理数据。在中国大陆使用 Mochi 时，发给这些服务的内容会传到境外。公开研究用到的搜索服务和网站也可能在境外。你配置的模型 API 在哪里处理数据，取决于你选择的服务方。Mochi 连接的飞书和 Aha Labs 的多维表格都使用飞书中国版。

## 运行与支持信息

本机保存运行日志，用于诊断事件、稳定标识和错误情况。原始日志可能包含路径与错误细节，不会自动上传，也不作为公开支持附件。

Mochi 不自动上传完整聊天记录或本机诊断报告。只有你主动导出并提交诊断时，支持方才收到该报告。当前诊断包含组件版本、运行和连接状态、队列数量、上下文用量及固定问题码，不包含账号邮箱、群和项目目录、消息、工作记录身份或凭据。你另外提供的截图或文字可能包含私人内容，请在提交前核对。

需要了解保留情况、提前删除你提交给 Aha Labs 的信息或请求其他处理时，请写邮件到 {{PRIVACY_CONTACT_EMAIL}}；本机卸载不会自动撤销这些已提交的信息。

## 停止使用和删除

你可以暂停伙伴、关闭群回应、取消资源选择或断开连接。服务端授权需要在对应服务方设置中单独撤销；Mochi 不把本机断开当成所有远端授权已撤销的证明。

App 内统一提供卸载入口，默认保留本机账号连接、设置和工作记忆；明确选择删除全部数据后，会删除 Mochi 拥有的本机产品数据，包括界面偏好、WebKit 存储和保存的窗口状态。已经发到群里的回复、写入 GitHub 的内容、模型服务保留的请求及向支持方提交的信息，不会因本机卸载而被删除。
